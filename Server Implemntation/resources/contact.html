Contact & Testing Information

This page provides testing instructions and examples for the Multi-threaded HTTP Server.

🌐 Basic GET Requests

Test these URLs in your browser:

  • Home page: http://localhost:8080/
  • About page: http://localhost:8080/about.html
  • This page: http://localhost:8080/contact.html
  • 404 test: http://localhost:8080/nonexistent.html

📁 Binary File Downloads

These links will trigger file downloads:

  • Download sample.txt (Text file as binary)
  • Download logo.png (PNG image)
  • Download photo.jpg (JPEG image)

Note: Files will be downloaded with Content-Disposition: attachment header.
