About This Multi-threaded HTTP Server

This is a multi-threaded HTTP server implemented in Python using low-level socket programming. It demonstrates advanced concepts in network programming, concurrent programming, and web server architecture.

Key Features

🧵 Thread Pool Management

Uses ThreadPoolExecutor with configurable pool size (default: 10 threads). Efficiently handles multiple concurrent connections without overwhelming system resources.

🔄 Keep-Alive Connections

Supports HTTP/1.1 persistent connections with 30-second timeout and maximum 100 requests per connection. Reduces connection overhead for multiple requests.

📁 Binary File Transfer

Properly handles binary file downloads (PNG, JPEG, TXT) with correct Content-Type and Content-Disposition headers. Files are read in binary mode to preserve data integrity.

📝 JSON POST Processing

Accepts and validates JSON data via POST requests. Creates unique timestamped files in the uploads directory with proper error handling.
