Welcome to Multi-threaded HTTP Server

This server supports:

  • HTML file serving with proper Content-Type headers
  • Binary file downloads (images, text files)
  • JSON POST requests with file storage
  • Persistent connections (Keep-Alive)
  • Multi-threaded request handling
  • Security features (path traversal protection, host validation)
